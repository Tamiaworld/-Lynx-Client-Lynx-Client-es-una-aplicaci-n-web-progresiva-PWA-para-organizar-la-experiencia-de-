# Lynx Client

Lynx Client es una aplicación web progresiva (PWA) para organizar la experiencia de Minecraft Bedrock.

## Funciones

- Acceso rápido a Minecraft.
- Instalación como aplicación cuando el navegador lo permite.
- Perfil de jugador y estadísticas manuales.
- Registro de mundos y notas.
- Lista de recursos favoritos.
- Tema oscuro y claro.
- Temporizador y retos de juego.
- Exportación e importación de copias JSON.
- Compatibilidad con caché para uso sin conexión.

## Archivos

- `index.html`: interfaz principal.
- `manifest.json`: nombre y configuración de instalación.
- `sw.js`: caché y funcionamiento sin conexión.
- `icons/icon.svg`: icono vectorial.
- `icons/icon-192.png`: icono para la PWA.
- `icons/icon-512.png`: icono de mayor resolución.

## Instalación

1. Conserva todos los archivos y carpetas.
2. Publica el proyecto mediante HTTPS.
3. Abre la dirección en un navegador compatible.
4. Selecciona la opción de instalar aplicación.

## Importante

Lynx Client es un proyecto independiente. No es un launcher nativo, no instala Minecraft y no garantiza que el botón de jugar abra el juego en todos los dispositivos.
