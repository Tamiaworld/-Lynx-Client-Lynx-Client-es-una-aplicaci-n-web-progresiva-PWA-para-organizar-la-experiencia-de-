
# ⛏️ Otra Vida Launcher

**Tu aventura de Minecraft comienza aquí.**

Otra Vida Launcher es una aplicación web diseñada para organizar tu experiencia de Minecraft desde tu dispositivo Android.

## ✨ Características

- 🏠 Página de inicio personalizada.
- 👤 Perfil de jugador con nombre y avatar.
- 🌍 Registro y organización de mundos.
- 📦 Lista de recursos favoritos.
- 📊 Estadísticas de juego.
- 🎨 Tema claro y oscuro.
- 💾 Guardado local de datos.
- 📤 Exportación de copias de seguridad.
- 📱 Diseño adaptable a celulares.
- 🔌 Soporte para instalación como PWA.
- 🌐 Funciones básicas disponibles sin conexión después de la primera carga.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web App Manifest
- Service Worker

## 🚀 Instalación y uso

1. Descarga o clona este repositorio.
2. Abre `index.html` para revisar el diseño.
3. Para probar las funciones PWA, publica el proyecto mediante HTTPS.
4. Abre la página publicada en Chrome para Android.
5. Si el navegador ofrece la opción, selecciona **Instalar aplicación** o **Añadir a pantalla de inicio**.

## 📱 Compatibilidad

Diseñado para navegadores modernos, especialmente Chrome en Android.

La instalación como PWA depende de que la publicación, el manifiesto, el service worker y los iconos estén configurados correctamente.
